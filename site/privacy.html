Privacy and terms

Privacy

  • This site sets no cookies and uses no analytics or advertising trackers.
  • The “My stack” filter is saved only in your browser (local storage). It is never sent to a server.
  • The site is hosted on GitHub Pages. GitHub may process visitor data such as IP addresses; see GitHub’s privacy statement.
  • Links lead to third-party sites, which have their own policies.

Data sources and attribution

The data is collected automatically from public sources: CISA Known Exploited Vulnerabilities catalog, the NVD, OSV.dev, GitHub Security Advisories, the Kubernetes official CVE feed, Red Hat, Ubuntu, Debian, the Linux kernel CVE announcements, oss-security, CISA advisories, ENISA EUVD, SAP Security Patch Day and FIRST EPSS.

This product uses the NVD API but is not endorsed or certified by the NVD. EPSS scores are provided by FIRST (first.org/epss). Each provider’s own terms and attribution requirements apply, and the original sources prevail over this site.

Disclaimer

The information is provided as-is, for awareness only. It may be incomplete, delayed or wrong, and mitigations are general guidance, not a substitute for the vendor’s advisory. Priority is a simple ranking (exploited, then EPSS, then CVSS) and is not an assessment of your environment. Always verify against the vendor advisory before acting.
